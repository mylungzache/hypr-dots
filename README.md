## Dependencies
### Required
- [Hyprland](https://github.com/hyprwm/hyprland) (Tiling manager, Wayland compositor)
- [UWSM](https://github.com/Vladimir-csp/uwsm) (Universal Wayland Session Manager, tool that wraps Wayland compositors into systemd user units)
- [hyprpicker](https://github.com/hyprwm/hyprpicker) (Wayland color-picker)
- [Noctalia](https://github.com/noctalia-dev/noctalia) shell (Desktop shell, all-in-one)
- [Firefox](https://github.com/mozilla-firefox/firefox) (Web browser providing a range of customization)
- [kitty](https://github.com/kovidgoyal/kitty) (Terminal emulator)
- [SystemD](https://github.com/systemd/systemd) (Init)
- Screenshot Utility (Swash Recommended)
- Image Editor Utility (Swash Recommended)
### Optional
- [btop](https://github.com/aristocratos/btop) (Resource monitor that shows usage and stats for processor, memory, disks, network and processes.)
- [fastfetch](https://github.com/fastfetch-cli/fastfetch) (Feature-rich and performance oriented neofetch-like system information tool)
